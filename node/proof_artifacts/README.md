# Proof artifacts (§59 automated harness)

Generated by `scripts/final_serverless_proof.sh`.

- Each run writes `node/proof_artifacts/<run-id>/` (transcript, step results, redacted logs).
- `LATEST` / `LATEST_RUN_ID.txt` point at the most recent run.
