# Local developer proof artifacts (§59)

These ignored local directories are generated by the repository-root
`scripts/final_serverless_proof.sh` developer harness.
A `LATEST` pointer, when present in a developer workspace, identifies that
workspace's most recent run. Treat it as a dated transcript, not a reproducible
current result, production-readiness certificate, or external audit.

- Historical runs use `proof_artifacts/<run-id>/` for transcripts and redacted logs.
- `LATEST` / `LATEST_RUN_ID.txt` identify the last archived run, not the latest commit verification.
- Artifacts can contain ephemeral public identifiers even when seeds are scrubbed.
- For checks that can be run now, see [Serverless verification status](../FINAL_SERVERLESS_PROOF.md).
